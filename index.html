K-Beauty API Test

A development website for testing TikTok account authorization and uploading K-beauty video drafts through the official TikTok API.

About This Service

K-Beauty API Test is a development project for preparing and uploading short-form K-beauty video drafts to an authorized TikTok account.

How It Works

The account owner signs in with TikTok and grants the required permissions. Videos may then be transferred as drafts for review, editing, and final publication inside TikTok.

Development Status

This service is currently used for API development and sandbox testing. It is not affiliated with or endorsed by TikTok.
