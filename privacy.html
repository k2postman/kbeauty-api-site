Privacy Policy

K-Beauty API Test

1. Overview

This Privacy Policy explains how K-Beauty API Test handles information when testing TikTok account authorization and video-draft uploads through the official TikTok API.

2. Information We May Access

When a user voluntarily authorizes the service through TikTok, the service may access information permitted by the selected TikTok scopes, including:

  • TikTok user identifier or open ID
  • Display name and profile image
  • Authorization and access-token information
  • Video files and upload-related information provided by the user
  • Technical error and API-response information

3. How Information Is Used

Information is used only to authenticate an authorized TikTok account, test API functionality, upload user-selected videos as TikTok drafts, diagnose errors, and maintain the security of the testing process.

4. Current Storage Practices

This project is currently operated as a sandbox and local development test. TikTok credentials and authorization tokens may be temporarily processed on the operator's local device for testing purposes.

The project does not currently operate a public user database. If server-side storage is introduced in the future, this policy will be updated before that functionality is made available.

5. Sharing of Information

Personal information is not sold or rented. Information may be transmitted to TikTok as necessary to perform authentication and video-upload requests through TikTok's official services.

Information may also be disclosed when required by applicable law or when reasonably necessary to protect the security and integrity of the service.

6. Authorization Tokens

Access and refresh tokens are sensitive credentials. They are used only for authorized API operations and must not be published in this website, a public GitHub repository, or any publicly accessible file.

7. Data Retention and Deletion

Test information is retained only for as long as reasonably necessary to conduct API testing, resolve errors, or meet legal obligations.

A user may revoke the service's TikTok authorization through their TikTok account settings. A user may also request deletion of locally retained test information by contacting the project operator.

8. Security

Reasonable measures are used to protect authorization tokens and test information. However, no electronic transmission or storage method can be guaranteed to be completely secure.

9. Children's Privacy

This development project is not intended for children and does not knowingly collect personal information from children.

10. Third-Party Services

TikTok processes information according to its own terms and privacy policies. K-Beauty API Test is an independent development project and is not affiliated with, sponsored by, or endorsed by TikTok.

11. Changes to This Policy

This Privacy Policy may be updated when the project's features or data-handling practices change. The latest version will be published on this page.

12. Contact and Data Requests

Questions, authorization-revocation requests, and data-deletion requests may be submitted through the project operator's GitHub profile.
